# 鎏金水墨幻想提示词

把用户给出的任意主体或场景编译为稳定、可变化的“鎏金水墨幻想”图片风格。风格锁定材质、光线、空间和色彩，不锁定人物身份、物种、姿态或眼睛状态。

## 主体自由原则

- 主体可以是人物、群像、动物、神兽、植物、建筑、山水、器物、产品、抽象形态或无人空景。
- 始终保留用户明确给出的主体形态、数量、动作、表情、视角、地点、时代和关键物件。
- 不因风格样本曾出现神女而自动加入女性、闭眼、金冠、花钿、月牙、凤凰、古装或人脸。
- 用户没有指定人物时，不擅自添加人物；用户指定睁眼、奔跑、战斗、飞行或其他状态时，按原意呈现。
- 风格通过表面、光线与空间生效，不通过替换主体生效。

## 工作流

1. 提取不可改动事实：主体类别与典型形态、数量、动作或状态、关键部件、环境、画幅和输出意图。
2. 读取 [references/subject-compiler.md](references/subject-compiler.md)，先建立主体形态锁与可施加风格的表面区域。
3. 仅当主体是人物、类人形态，或用户明确要求发型、头饰、服饰时，读取 [references/hair-costume-grammar.md](references/hair-costume-grammar.md)。无人场景、动物、建筑、植物、器物与纯抽象默认不读取，也不套用人物造型。
4. 读取 [references/visual-grammar.md](references/visual-grammar.md)，选择一个主风格分支；只有用户明确要求混合时才组合两个分支。
5. 读取 [references/model-recipes.md](references/model-recipes.md)，分别编写 ImageGen 与 Midjourney 版本，不机械翻译同一段文字。
6. 读取 [references/failure-constraints.md](references/failure-constraints.md)，只添加与当前主体和材料有关的约束。
7. 仅当用户询问风格来源、研究过程或证据链时，读取 [references/evidence-index.md](references/evidence-index.md)。
8. 输出前检查：主体保真、人物造型完整、材料不串线、金色面积克制、单一主光、空间可读、两种模型格式和 Midjourney 后缀。

## 默认视觉决策

用户没有指定时：

- 主分支：梦幻透明鎏金；辅以水墨金箔的冷色负空间。
- 主体处理：保留原始轮廓，在局部表面、内部脉络或周围空间加入鎏金系统，不把主体整体金属化。
- 材料：从实心花丝金属、透明琥珀金液/玻璃、贴附碎金箔、湿墨/黑漆、象牙树脂/云雾中选择 2–3 种；不得把它们混成一种不透明金色物质。
- 色彩：蓝黑或青灰阴影、暖象牙中间调、香槟金高光，朱砂只作小面积节奏点。
- 光线：一个暖色主光或掠光，极弱冷青补光；高光集中在少数局部，不做全屏金黄。
- 构图：一个主形状、一条辅助弧线或 S 曲线、至少一块冷色或暗色负空间。
- 画幅：环境和叙事默认 16:9；单体立像或竖向主体默认 3:4。用户指定比例时严格服从。
- 文本：画面内无文字、标志、水印、字幕或界面元素，除非用户明确要求。

## 人物造型硬规则

仅在人物或类人主体分支启用：

- 用户已指定时代、身份、现代/历史服装、发型或头饰时，原设定优先；鎏金系统只补充材质、工艺和光线，不改写服装类别。
- 用户未指定人物造型时，必须选择一个与动作相容的发式/头饰档位和一套服装分层，不得只写“古风女子、华丽发饰、飘逸长裙”。
- 发部至少写清：发型结构、干湿/松紧状态、动态方向、发饰种类、固定位置或连接关系。头饰可以稀疏、平衡或仪式化，但不是每个人物都戴巨型金冠。
- 服装至少写清：不透明贴身或内层、主体丝绸/锦缎层、可选半透明纱层，及金线/碎金箔落在衣领、袖口、裙摆或褶皱中的具体位置。
- 透明鎏金弧流属于空间特效时，必须与薄纱、水袖和裙摆分开描述；不要把衣袖熔成金液或把全套服装变成金属。
- 奔跑、打斗、飞行和舞蹈优先使用牢固的小型簪梳、短流苏或稳定发髻；巨型头冠只用于用户明确的仪式、圣像或华丽静态场景。

## 材料硬规则

- 实心花丝金属：不透明、硬边、精细镂空或浮雕，只用于冠饰、器物、局部甲片、建筑构件等确实需要金属结构的位置。
- 透明琥珀金液/玻璃：透明、折射、带厚度和亮边，形成薄片、细丝、滴状或弧流；背景和主体仍应透过它可见。
- 贴附碎金箔：扁平、破碎、贴在裂纹、山脊、树根、鳞片、衣褶或器物纹理上，由掠光依次显现，不自行发光。
- 湿墨/黑漆：深黑到青黑，可有湿润镜面、渗化边缘或厚薄变化，但不把整景变成石油洪水。
- 每张图只确定一个主鎏金机制和一个辅助机制。不要同时堆满冠饰、金液、金箔、金雨、金雾和金色建筑。
- 避免只写 molten gold 或 luminous gold；必须说明透明度、附着位置、形态、光源与覆盖范围。

## 输出模式

### 仅提示词

用户说“给提示词”“扩写”“做成这种鎏金风格”时依次输出：

1. 画面设计：不超过 4 行中文，说明主体形态锁、主分支、构图、主材料和光线。
2. ImageGen Prompt：一段可直接使用的中文自然语言提示词；用户要求英文时改为英文。
3. Midjourney 8.2 Prompt：一段可直接粘贴的英文提示词。
4. 可调选项：最多 3 项，如改变材料机制、画幅或冷暖倾向；不要自动生成冗长变体。

### 参考图提示词

用户提供参考图时：

1. 先识别参考图负责主体、构图、材质还是综合色彩，不默认一张图承担全部角色。
2. 保留用户明确指定的参考作用；未指定时说明推断。
3. 只输出提示词，除非用户明确要求生成图片。
4. 不发明图片 URL、Style Reference、Object Reference、seed 或个性化代码。

### 直接生图

用户明确说“直接生图”“现在生成”时：

1. 内部先完成 ImageGen 提示词，不要求用户重复确认。
2. 当前环境有图像生成工具时按工具说明生成。
3. 同时保留 ImageGen 与 Midjourney 8.2 提示词以便复用。
4. 没有生成能力或生成失败时明确说明，不把提示词冒充成图片结果。

## Midjourney 8.2 硬规则

- 每条主提示词必须完全以 --v 8.2 结束，后面不得再有字符或参数。
- 参数位于描述正文之后。默认使用 --ar、--s、--c、--no、--v。
- 梦幻鎏金默认不使用 --raw，以免压低材质的诗意解释；严格形态复刻时才谨慎加入。
- 建议起点：环境叙事使用 --ar 16:9 --s 350 --c 5 --v 8.2；单体立像使用 --ar 3:4 --s 400 --c 5 --v 8.2。
- 不添加用户未提供的图片 URL、--sref、--oref、--seed、--profile、个性化代码或账号参数。
- 不宣称 V8.2 已获官方文档确认。用户报告版本不可用时，另列 V8.1 兼容版，不静默替换主版本。

## 内容保真优先级

冲突时按此顺序取舍：

1. 用户明确主体、数量、动作和形态
2. 用户明确身份、时代、眼睛状态、发型与服装类别
3. 主体关键部件、人物造型连接关系与动作可读性
4. 镜头和构图
5. 主鎏金材料机制
6. 装饰、粒子和气氛

例如“睁眼的黑豹在雨夜竹林奔跑”必须先保住黑豹、睁眼、奔跑和竹林；鎏金只沿湿毛、肌理或雨幕形成局部金箔/透明弧流，不能把它改成闭眼神女、金色雕像或静止宠物肖像。

## 质量门槛

- 去掉人物姓名后，风格仍应可应用于动物、建筑、器物或纯景观。
- 主体是否保持原始典型轮廓、数量、动作和关键部件。
- 是否明确区分实心金属、透明金液和贴附金箔，未发生材质串线。
- 金色是否由局部反射和材质产生，而非全屏黄光、霓虹或无来源神光。
- 是否只有一个视觉焦点、一个主光源和一套一致透视。
- 是否保留蓝黑/青灰负空间，避免过饱和红金和廉价游戏 CG。
- 人物分支是否明确写出发型结构、发饰固定点、服装层次、织物材质和鎏金落点；是否与动作和时代相容。
- 人物分支是否防止头冠吞脸、流苏穿脸、发簪漂浮、薄纱裸露、衣袖与金液融合；非人物分支是否完全没有无故加入人物造型。
- 是否排除与当前主体有关的形态错误、重复肢体、熔化结构、文字和水印。
- Midjourney 主提示词是否严格以 --v 8.2 结束。
